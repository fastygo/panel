# API Stability

Panel starts as a `v0` package.

## Stable Enough For Early Consumers

- `Panel`
- `Registry`
- `Route`
- `MenuItem`
- `NavigationGroup`
- `Asset`
- `EditorProviderRegistration`
- `Principal`
- `Policy`

## Experimental

- `Resource`
- `Page`
- `Widget`
- `Action`
- `FormSchema`
- `TableSchema`
- `DataSource`
- `RecordType`
- `Workflow`
- `Report`
- `ImportExportDescriptor`
- `PrintDescriptor`

These contracts should stabilize only after GoCMS and at least one non-CMS example consume them.
