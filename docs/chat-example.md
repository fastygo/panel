# Chat Example

A chat operations package can use panel for moderation and assistant workflows:

- `chatpanel.ConversationsPage`
- `chatpanel.ModerationQueueResource`
- `chatpanel.AssistantRunsWidget`
- `chatpanel.EscalateAction`
- `chatpanel.ResolveConversationAction`

Messages, moderation decisions, model runs, transcripts, and event streams stay in the chat data plane.
