# CRM Example

A CRM package can use panel without importing CMS code.

Possible descriptors:

- `crmpanel.LeadsResource`
- `crmpanel.DealsResource`
- `crmpanel.ContactsResource`
- `crmpanel.PipelineWidget`
- `crmpanel.AssignOwnerAction`

The CRM data plane owns lead scoring, pipeline rules, tasks, notes, email sync, and persistence. Panel only describes the operator experience.
