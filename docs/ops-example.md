# Operations Example

An operations package can use pages, widgets, resources, and actions:

- `opspanel.ServicesPage`
- `opspanel.IncidentsResource`
- `opspanel.MetricsWidget`
- `opspanel.AlertAction`
- `opspanel.AcknowledgeIncidentAction`

Metrics, logs, traces, alerts, service health, and incident automation remain in the operations data plane.
